# Gym Helper

[English](README.en.md) | **Русский**

Telegram-бот с ИИ для ведения дневника силовых тренировок, анализа прогресса и ответов на вопросы о фитнесе. Общение — обычными сообщениями, без специальных команд для каждой задачи.

## Возможности

- Запись упражнений, подходов, весов, повторений и RIR из текста.
- Распознавание тренировки по одному или нескольким скриншотам, отправленным альбомом.
- Предпросмотр тренировки перед сохранением: подтвердить, исправить словами или отменить.
- Хранение тренировок и истории переписки в PostgreSQL.
- Анализ последней тренировки, истории упражнения и нескольких последних тренировок.
- Ответы на вопросы о тренировках с учётом недавней переписки.
- Поиск исследований через Tavily и объединение научных данных с личной историей тренировок в одном ответе.
- Глубокое исследование с несколькими поисковыми задачами для подробных обзоров и сравнительных отчётов.
- Выбор языка через `/start`, сохранение предпочтения и смена языка командой `/language`.

## Стек

Python, aiogram, LangChain, LangGraph, OpenAI, Tavily, PostgreSQL 17, SQLAlchemy и Alembic. Модель в текущем коде — `gpt-4o`, настраивается в [`app/llm.py`](app/llm.py).

## Локальный запуск

Понадобятся Python 3.11+ (рекомендуется), Docker с Compose, токен Telegram-бота и ключи OpenAI и Tavily.

### 1. Установите зависимости

В каталоге клонированного репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows PowerShell активация окружения: `.\.venv\Scripts\Activate.ps1`.

### 2. Настройте окружение

Скопируйте `.env.template` в `.env` и заполните его:

```dotenv
OPENAI_API_GPT=your_openai_api_key
TAVILY_API_KEY=your_tavily_api_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql+asyncpg://gym_helper:gym_helper@localhost:5433/gym_helper
```

Ключ OpenAI задаётся переменной `OPENAI_API_GPT`, которую читает [`app/config.py`](app/config.py).

Токен Telegram-бота создаётся через `@BotFather`. Не публикуйте `.env` и реальные ключи в репозитории. Параметры базы в примере соответствуют локальному `docker-compose.yml`.

### 3. Запустите базу и примените миграции

```bash
docker compose up -d postgres
python -m alembic upgrade head
```

Дождитесь готовности PostgreSQL перед запуском миграций. Compose запускает только базу; её данные сохраняются в Docker volume `postgres_data`. Порт базы на компьютере — `5433`.

### 4. Запустите бота

```bash
python main.py
```

Бот получает сообщения через long polling. При запуске он регистрирует команды `/start` и `/language` в меню Telegram. Откройте бота, отправьте `/start` и укажите язык общения, если он ещё не выбран.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Запускает общение: запрашивает язык, если он ещё не выбран, или показывает приветствие на сохранённом языке. |
| `/language` | Предлагает ввести новый язык общения, например «русский», «English» или «polski». Выбор сохраняется в базе. |

Для записи тренировок, анализа и поиска достаточно обычного сообщения: бот сам определяет подходящий режим.

## Примеры использования

```text
Запиши тренировку: приседания 60 кг — 3 подхода по 8, RIR 2.
```

Проверьте распознанные данные и нажмите ✅ для сохранения, ✏️ для исправления или ❌ для отмены. Пример исправления: «Во втором подходе было 10 повторений».

Можно отправить скриншот тренировки или несколько скриншотов одной тренировки альбомом. После сохранения задайте вопрос:

```text
Какой вес я использовала в приседаниях в прошлый раз?
Сравни мои последние тренировки.
Найди исследования о тренировках до отказа.
Проанализируй мои приседания и сравни с актуальными исследованиями.
```

В режиме анализа бот может обращаться и к истории тренировок, и к поиску исследований, объединяя результаты в одном ответе. Если данных недостаточно, он может запросить уточнение. При использовании исследований ему задано приводить ссылки на источники, когда они доступны.

Для подробного обзора явно попросите глубокое исследование, например:

```text
Проведи глубокий обзор исследований гипертрофии за 2020–2026 годы.
Подготовь подробный сравнительный отчёт о пяти методиках силовых тренировок.
```

Такие запросы направляются в отдельный процесс LangGraph: планирование поисковых задач, поиск через Tavily, оценка полноты результатов и подготовка итогового ответа. Обычные вопросы об исследованиях обрабатываются в режиме анализа.

## Структура проекта

```text
app/
  telegram_bot.py     Обработчики Telegram и подтверждение тренировок
  router.py           Определение намерения пользователя
  llm.py              Настройка модели
  modes/              Диалог, тренировки, исследования и выбор языка
  models/             Модели базы данных
  schemas/            Pydantic-схемы тренировок
  services/           Работа с пользователями, историей и тренировками
  states/             Состояния диалога
  tools.py            Поиск исследований и инструменты доступа к истории тренировок
migration/            Миграции Alembic
docker-compose.yml    Локальный PostgreSQL
main.py               Точка входа
```

## Проверка и текущие ограничения

`test_workout_history.py` и `test_tools.py` — ручные интеграционные скрипты. Они требуют настроенного окружения, базы с миграциями и данных пользователя с `user_id=1`; `test_tools.py` также обращается к OpenAI.

```bash
python test_workout_history.py
python test_tools.py
```

Черновики тренировок и состояния диалога хранятся в памяти процесса и теряются при перезапуске. Сохранённые тренировки и переписка остаются в PostgreSQL. Для контекста диалога загружаются последние 10 сообщений.

Текст и изображения обрабатываются через OpenAI, поисковые запросы — через Tavily. Работа с внешними API требует доступа к сети и может тарифицироваться провайдерами.
